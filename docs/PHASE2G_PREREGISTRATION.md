# Phase 2g 사전등록 — 테이커 매수 흐름 앙상블 단일 가설 검증

기준일: 2026-10-20 KST. 상태: **등록됨, 검증 계산 전.** 근거: [Decision 0027](decisions/0027-phase2f-stop-and-register-phase2g.md).

## 1. 배경

Phase 2f([등록](PHASE2F_PREREGISTRATION.md))는 개발 게이트를 통과한 전략군이 없어 `STOP_NO_EDGE`였다. 검증 구간은
계산하지 않았다. 다만 P3(테이커 매수 흐름 추종)는 전략군 전체가 일관되게 기준선을 앞섰다.

- 개발 구간(2020-07~2023-12)에서 6개 설정 모두 Sharpe 1.47~1.83이었다. 기준선 최고는 BTC·ETH 1.19다.
- 6개 설정 모두 최대 낙폭(21~38%)이 BTC 보유보다 작았다.
- 탈락 사유는 PBO 0.73 하나다. 설정끼리 거의 같아서, 개발 구간의 1등이 나머지 구간에서 중위 아래로 내려가는 일이 잦았다.
  비용 2배에서도 Sharpe 1.62로 기준선을 넘었다.
- **주의:** 롱 쪽만 돌리면 +538%, 숏 쪽만 돌리면 −19%였다. 수익 대부분이 2020~2021 상승장의 롱 쪽에서 나왔다.

이 등록은 P3 전략군을 **하나의 가설**로 고정하고, 2f 검증 구간에서 **한 번** 검증한다. 최고 설정 하나를 고르지 않고
6개 설정의 앙상블로 시험해 선택 편향을 줄인다.

## 2. 가설 (고정)

**전략 T1:** 매주 일요일 종가에 결정하고 월요일 00:00 UTC 시가에 체결한다. 목표 비중은 P3 6개 설정 목표 비중의 단순 평균이다.

- 6개 설정: L∈{3,7,14} × K∈{3,5}.
- 각 설정: 결정 시점 무기한 거래대금 상위 20개 중, 테이커 매수 비중 L일 평균 상위 K개를 롱, 하위 K개를 숏한다.
  각 쪽 50%다. 정의는 Phase 2f §5와 같다.

비용·체결·유니버스·데이터는 Phase 2f와 같다. 패널 해시는 `8f68ecb0…`이다. 총노출은 1 이하이고 레버리지는 없다.

## 3. 검증

- **구간:** 2024-01-01 ~ 2026-09-29(Phase 2f 검증 구간). 테이커 흐름 전략 성과로는 처음 계산한다. 오염 내용은 Phase 2f §3과 같다.
- **게이트 (모두 충족해야 `CANDIDATE`):** Phase 2f V1~V5와 같다.
  - V1: 순수익 > 0이고 순 Sharpe ≥ 0.5.
  - V2: 2024년과 2025-01~2026-09에서 각각 순수익 > 0.
  - V3: 비용 2배에서도 순수익 > 0.
  - V4: 최대 낙폭 < 같은 구간 BTC 보유 최대 낙폭.
  - V5: 2020-07-01~2026-09-29 일별 수익률의 Deflated Sharpe ≥ 0.95. 시험 수 M=188(2d 120 + 2e 1 + 2f 66 + 이번 1)이고,
    Sharpe 분산은 Phase 2f 66개 설정의 개발 Sharpe를 쓴다.
- **판정:**
  - **`CANDIDATE`:** 주문 없는 전진 관측 대상이 된다. 기준은 Phase 2f §6과 같다(3개월 중간 점검, 6개월 최종). 서버 반영은 사용자 승인 후에 한다.
  - **`FAIL`:** 가설을 기각한다. 이 검증 구간은 이후 어떤 가설의 확인 증거로도 쓰지 않는다.
