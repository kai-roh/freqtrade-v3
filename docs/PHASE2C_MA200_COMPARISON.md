# Phase 2c 후속: 고정 MA200 실효성 비교 계획

기준일: 2026-10-02 KST. 상태: **계획 고정, 미실행**. 이 문서를 커밋한 뒤에만 현물 데이터를 받고 비교를 실행한다.

이것은 **진단**이다. 쓰는 데이터는 모두 이미 본 개발 데이터이고, 결과가 좋아도 승격·주문 근거가 되지 않는다.
목적은 하나다. Phase 2c에서 결과를 본 뒤 눈에 띈 MA200 대조군이, 실제 대안인 **현물 보유**와 실제 주문 제약까지
반영했을 때도 "보유 수익을 대부분 유지하면서 하락 위험을 줄이는" 장점을 유지하는지 확인해, **주문 없는 전진 관측을
등록할 가치가 있는지** 정한다.

## 1. 바꾸지 않는 것

MA200 규칙은 Phase 2c 그대로다: 매일 00:00 UTC, `sign(C_t − 최근 200일 종가 평균) × v`, `v = min(1, 0.25/(σ_60d·√365))`,
자산별 슬리브의 절반, 1배 이하, 재조정 임계 0.20, 01:00 시가 taker. **MA 기간·임계값·종목·변동성 목표를 탐색하지
않는다.** 롱·현금 변형이나 숏 제거도 넣지 않는다(별도 가설).

## 2. 비교 대상 (같은 기간·자본·위험 산정)

| 이름 | 시장 | 규칙 | 비용 |
|---|---|---|---|
| MA200-perp | USD-M 무기한 | MA200(롱·숏) | taker 5 bps + 슬리피지 2/5 bps, 실제 펀딩 |
| BHVT-perp | USD-M 무기한 | `w = v`(항상 롱) | 같음 |
| BHVT-spot | 현물 | `w = v`(항상 롱), 현물 가격 | taker 10 bps(2026-10-02 조회) + 슬리피지 2/5 bps, 펀딩 없음 |

- 기간: **2022-08-01 ~ 2026-10-01**(Phase 2c 대조군과 같은 기간)을 판정에 쓴다. 2020-08-01 ~ 2026-10-01은 참고로만 보고한다.
- 슬리브 500 USDT, 자산별 250 USDT 한도.
- 현물 BHVT의 변동성 스케일은 현물 종가로 계산한다(같은 규칙을 현물에서 재현).

## 3. 거래소 제약 모드 (수정된 규칙)

Phase 2c 8번 게이트의 "목표 보유량 기준" 검사를 거래소 규칙대로 고친다.

- 목표 수량을 수량 간격으로 0 방향 내림한다.
- 주문 차액이 포지션을 **줄이는** 주문(같은 방향에서 작아지거나 0으로)이면:
  - 무기한: reduce-only로 최소 주문금액 면제(Binance -4164).
  - 현물: 면제 없음. 차액이 최소 주문금액 미만이면 주문하지 않는다.
- 포지션을 **늘리거나 방향을 바꾸는** 주문은 차액 명목이 최소 주문금액 이상일 때만 낸다. 미만이면 건너뛴다(건너뜀으로 집계).
- 필터: 무기한 `evidence/phase2b/implementability.json`(BTC 0.001/50, ETH 0.001/20), 현물
  `evidence/phase2c/spot-filters-20261002.json`(BTC 0.00001/5, ETH 0.0001/5). 2026-10 값을 과거 가격에 적용하는 근사다.

이상 모드(연속 수량, 제약 없음) 결과도 함께 보고한다. 판정은 제약 모드로 한다.

## 4. 판정 기준 (제약 모드, MA200-perp vs BHVT-spot, 정상·스트레스 비용 모두)

| # | 기준 |
|---|---|
| C1 수익 유지 | MA200 순손익 ≥ 0.70 × BHVT-spot 순손익 |
| C2 낙폭 감소 | MA200 MDD ≤ (2/3) × BHVT-spot MDD |
| C3 효율 | MA200 연환산 수익 / MDD ≥ BHVT-spot의 같은 비율 |
| C4 최악 연도 | MA200의 최악 달력연도 손익 ≥ BHVT-spot의 최악 달력연도 손익 |
| C5 구현 | MA200의 건너뛴 주문 ≤ 주문 시도의 10% |

- 모두 통과 → `OBSERVE_ELIGIBLE`: MA200을 고정한 주문 없는 전진 관측을 **등록할 수 있다**(등록 여부는 사용자 결정).
- 하나라도 실패 → `PAUSE_RESEARCH`: 새 전략군을 바로 추가하지 않고 연구를 쉰다.
- BHVT-perp 대비 같은 기준 결과는 참고로 보고한다.

**고지:** 이 기준은 Phase 2c에서 MA200과 BHVT-perp의 이상 모드 결과(순손익 340.5 vs 339.6, MDD 13.4% vs 24.8%)를
본 뒤에 정했다. 새로 드러나는 정보는 현물 대조군과 수정된 제약 모드다. 단일 후보이므로 PBO는 계산하지 않으며,
선택 편향이 없다고 간주하지 않는다.

필수 보고(기준 아님): 손익 분해(가격·펀딩·수수료·슬리피지), 연도별 손익, MA200 방향 전환 횟수(자산별), 연간 주문 수,
시장 노출 시간, 참고 기간 결과, 수정된 제약 규칙으로 다시 계산한 Phase 2c H4 walk-forward(8번 게이트 참고값).

## 5. 전진 관측을 등록하게 될 경우의 원칙 (지금 정하는 최소선)

- 6개월은 첫 점검이지 판정이 아니다. 판정에는 기간과 함께 **MA200 방향 전환 2회 이상**과 **BHVT 기준 10% 이상 하락 구간
  1회 이상**을 겪었는지를 최소 조건으로 둔다. 조건 미달이면 관측을 연장한다.
- 관측 중 규칙·대조군 변경 금지, 주문 없음.
