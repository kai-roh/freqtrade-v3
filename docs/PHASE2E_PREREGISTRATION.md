# Phase 2e 사전등록 — 모멘텀 앙상블 단일 가설 확인 검증

기준일: 2026-10-19 KST. 상태: **등록됨, holdout 계산 전.** 근거: [Decision 0024](decisions/0024-phase2d-stop-and-register-phase2e.md).

## 1. 배경

Phase 2d([등록](PHASE2D_PREREGISTRATION.md))는 개발 게이트를 통과한 전략군이 없어 `STOP_NO_EDGE`였다. holdout에서는
기준선만 계산했고 전략은 계산하지 않았다. 다만 개발 결과에는 한 묶음이 일관되게 기준선을 앞섰다.

- 묶음: 횡단면 모멘텀(F1), 유니버스 N=10, BTC 시장 필터.
- 10개 설정 모두 BTC 보유 Sharpe(0.75)보다 높았다. Sharpe 0.70~1.11, 중위 0.95.
- CAGR 중위는 51%(BTC 31%), 최대 낙폭 중위는 66%(BTC 81%).
- 120개 시험 기준 Deflated Sharpe는 최고 설정도 0.55라 유의하지 않았다.

이 등록은 이 묶음을 **하나의 가설**로 고정한다. 그리고 선택에 쓰이지 않은 holdout에서 **한 번** 검증한다.
최고 설정 하나를 고르지 않고 10개 설정의 앙상블로 시험해, 선택 편향을 줄인다.

## 2. 가설 (고정)

**전략 E1:** 매주 일요일 종가에 결정하고 월요일 00:00 UTC 시가에 체결한다. 목표 비중은 아래 10개 설정 목표 비중의 단순 평균이다.

- 공통 설정: F1, N=10, BTC 종가가 100일 평균보다 높을 때만 투자.
- L∈{7,14,30,60,90}일 수익률 × K∈{3,5}.
- 각 설정의 정의는 Phase 2d §5 F1과 같다.
- 결과적으로 시장 필터가 꺼지면 전부 현금이고, 켜지면 거래대금 상위 10개 중 모멘텀 상위 종목에 비중을 나눈다.

비용·체결·유니버스·데이터(패널 해시 `fc5b6807…`)는 Phase 2d와 같다. 레버리지는 없다.

## 3. 검증

- **구간:** 2025-01-01 ~ 2026-09-29(Phase 2d holdout과 동일). 전략 성과로는 처음 계산한다.
- **게이트 (모두 충족해야 `PASS`):**
  - H1: 순수익 > 0.
  - H2: 순 Sharpe ≥ 0.5.
  - H3: 순 Sharpe ≥ 같은 구간 BTC 보유 Sharpe.
  - H4: 최대 낙폭 < 같은 구간 BTC 보유 최대 낙폭.
- **판정:**
  - **`PASS`:** E1을 주문 없는 전진 관측에 올린다.
  - **`FAIL`:** 이 가설을 기각한다. 이 holdout은 더 이상 어떤 가설의 확인 증거로도 쓰지 않는다.
- **한계(미리 적어 둠):** holdout은 21개월이다. Sharpe 1 전략도 이 기간의 t값은 약 1.3이라 통계적으로 확정하지 못한다.
  `PASS`는 "개발 결과가 처음 보는 기간에서 반박되지 않았다"는 뜻이지 수익 확정이 아니다.
